# Order Management System

A lightweight backend system for order creation, status management, query and simple statistics, designed for small‑scale business scenarios.

## Features
- Create, edit and delete orders
- Order status transition: Pending Payment, Paid, Shipped, Completed, Cancelled
- Filter and paginate order records
- Associate customer information with orders
- Basic order statistics
- REST‑style API interfaces

## Tech Stack
- Language: Python
- Database: SQLite / MySQL
- Framework: FastAPI / Flask
